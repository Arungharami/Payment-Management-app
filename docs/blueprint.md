# **App Name**: LiquorPay

## Core Features:

- User Authentication: Secure sign-up/log-in via email, Apple ID, or Google with OTP/biometric options.
- Vendor Management: Add and manage vendor accounts, payment links, and details securely.
- Payment Processing: Integrate bank (ACH) and card payments via Plaid/Stripe with one-click and 'Pay All' options.
- Notifications & Tracking: Push notifications for due dates/failed payments and a payment history with downloadable receipts.
- Secure Data Storage: Utilize Base44 encryption to ensure sensitive data (like bank details and vendor credentials) remains secure, and use tokenized payments.
- Report Generation: Users can create useful insights by downloading monthly vendor spending reports.
- Fraud Detection: The backend system acts as a fraud detection tool, preventing payments being made to unusual vendors.

## Style Guidelines:

- Primary color: Soft gold (#D4AF37) to evoke a sense of wealth and trust.
- Background color: Light beige (#F5F5DC), providing a clean and soft backdrop.
- Accent color: Muted green (#8FBC8F), used to highlight key actions and information.
- Body and headline font: 'SF Pro', sans-serif, known for its legibility and clean appearance in Apple products.
- Use vendor logos where available, combined with minimalist icons for navigation and actions.
- Employ a card-style layout with rounded corners for vendor lists to maintain a modern feel.
- Use smooth, subtle animations for transitions and user interactions to enhance user experience.
